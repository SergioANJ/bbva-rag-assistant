# BBVA RAG Assistant

Asistente conversacional basado en RAG (Retrieval-Augmented Generation) que responde
preguntas sobre el contenido público del sitio https://www.bbva.com.co/.

> 🚧 En construcción. La documentación completa se agregará al finalizar el proyecto.

## Desarrollo local

Requisitos: Python 3.12 y [uv](https://docs.astral.sh/uv/).

```bash
uv sync
cp .env.example .env
uv run pytest
```
